# Tests

Purpose: exercise C and Python behavior, persistence, parsing, security adapters and survey sanitization with focused fixtures. Run `../test.sh` from the repository root; optional PyNaCl enables the sealed-request cases. `test_boundaries.py` exercises private-demo connection quotas, overload, deadlines, pipelining and recovery with synthetic loopback clients. `test_cmake_install.sh` uses CMake, a C toolchain, ldd and Python to test Linux package installation, relocation and static/shared consumers.
