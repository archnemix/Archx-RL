# Tests

Purpose: exercise C and Python behavior, persistence, parsing, security adapters and survey sanitization with focused fixtures. Run `../test.sh` from the repository root; optional PyNaCl enables the sealed-request cases. `test_boundaries.py` exercises private-demo connection quotas, overload, deadlines, pipelining and recovery with synthetic loopback clients. `test_cmake_install.sh` uses CMake, a C toolchain, ldd and Python to test Linux package installation, relocation and static/shared consumers. `test_smbios.c` contains synthetic bounded firmware fixtures; `fuzz_smbios.sh` runs a fixed-duration libFuzzer smoke using synthetic seeds. The Windows-only firmware test prints availability, never identifiers. `test_uuid_value.c` and the macOS-only `test_macos_cf_uuid.c` exercise synthetic UUID validation and CF type/ownership without any registry access. `test_observation_index.py` compares a bounded inverted index with an independent linear model, covers saturation, concurrent deduplication, bounded expiry backlogs and indexed-heap invariants; `test_sqlite_engine.py` additionally checks seeded memory/SQLite parity. `test_crypto_differential.py` compares deterministic synthetic SHA-256 and HMAC cases with Python hashlib/hmac in addition to C known-answer vectors. `test_output_faults.c` exercises JSON helper bounds and synthetic output-allocation failures with a fake collector. `test_coverage.c` verifies ABI-v1 availability weights, all eight synthetic readable/unreadable combinations and the fixed fallback marker. `test_canonical.c` tests sorted synthetic signal serialization, exact and short buffers, null inputs, invalid counts, and unterminated fields; `test_output_faults.c` also injects canonicalization failure. `test_metrics.py` exercises concurrent fixed-schema metrics, marker privacy, instrumentation faults, and opt-in HTTP handler sharing.
