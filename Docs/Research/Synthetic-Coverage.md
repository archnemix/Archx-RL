# Separate synthetic coverage reports

This is partial evidence toward #41, not an exhaustive test suite or release gate. The read-only `Synthetic coverage` PR/push workflow runs `tools/coverage_smoke.sh` and uploads a short-lived artifact containing separate `c/`, `python/` and `javascript/` reports. To reproduce on Linux, install `demo/requirements-secure.txt` and `tests/requirements-coverage.txt`, run `npm ci --prefix bindings/node`, `npm ci --prefix demo/browser`, and `npm run build --prefix demo/browser`; then invoke `sh tools/coverage_smoke.sh /absolute/path/to/a/new/report-directory`. GCC/gcov, Node and Python are required. The script refuses an existing output directory.

- **C:** GCC/gcov line, branch and call results for one actual ABI test against a synthetic collector, with separately instrumented C objects. This is not coverage of real Linux collection, Windows/macOS product code, every C test or sanitizers.
- **Python:** coverage.py line/branch XML and text for a selected set of synthetic limiter, persistence, key-rotation and security tests. The report includes measured `demo` files, including unexecuted ones; it is not coverage of every Python package, adapter or command.
- **JavaScript:** V8 function/range *records* for the Node binding against a synthetic C collector and the bundled browser client run under Node against loopback synthetic tests. Counts are summed per process, may duplicate functions, are not line/branch percentages, and the browser bundle contains third-party code. This is **not Chromium or browser-instrumented coverage**. Raw V8 dumps are discarded; only fixed-target aggregate counts are retained.

No coverage threshold or production readiness assertion is implied. Runs depend on toolchain/version, instrumentation and selected tests; do not combine these reports into a single percentage. Coverage measures execution, not test quality or security. Input fixtures are synthetic and the report does not include database or raw V8 files. Logs and artifacts must still be reviewed before wider publication. Missing scheduled fuzzing evidence, credentialed staging, capacity budgets, broad fault tests and other release gates remain open.
