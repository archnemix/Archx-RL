# Python prototype

Purpose: Linux-native signal collection, request-policy engines, local HTTP demonstration and optional security adapters. See the root README for setup, privacy and production limitations. `site/` contains the synthetic frontend. The private demo server uses `bounded_server.py` for per-process connection admission; it is not a production server. `observation_index.py` provides bounded, deduplicated process-local history and name/token postings; it expects the engine lock and fails closed when full. An indexed expiry heap bounds observation cleanup to 64 removals per check; unfinished cleanup fails closed until a later request. Popular tokens can produce capacity-sized candidate sets, window cleanup still scans its bounded store, and no idle cleanup is scheduled. `metrics.py` provides optional process-local fixed-category counters and disjoint timing buckets for `RequestService.check`; no metrics endpoint or complete connection/HTTP coverage is provided.
