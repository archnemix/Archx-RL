# Python prototype

Purpose: Linux-native signal collection, request-policy engines, local HTTP demonstration and optional security adapters. See the root README for setup, privacy and production limitations. `site/` contains the synthetic frontend. The private demo server uses `bounded_server.py` for per-process connection admission; it is not a production server. `observation_index.py` provides bounded, deduplicated process-local history and name/token postings; it expects the engine lock and fails closed when full. Expiration still scans all stored observations per request and popular tokens can produce capacity-sized candidate sets.
