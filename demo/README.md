# Python prototype

Purpose: Linux-native signal collection, request-policy engines, local HTTP demonstration and optional security adapters. See the root README for setup, privacy and production limitations. `site/` contains the synthetic frontend. The private demo server uses `bounded_server.py` for per-process connection admission; it is not a production server. `observation_index.py` provides bounded, deduplicated process-local history and name/token postings; it expects the engine lock and fails closed when full. Indexed expiry heaps (memory) and indexed bounded SQL deletions (SQLite) remove at most 64 expired windows and 64 expired observations per valid check; unfinished cleanup fails closed until later requests. Malformed precharges only clean windows. Popular tokens can produce capacity-sized candidate sets, SQLite transaction work is not wall-clock bounded, and no idle cleanup is scheduled. `metrics.py` provides optional process-local fixed-category counters and disjoint timing buckets for `RequestService.check`; no metrics endpoint or complete connection/HTTP coverage is provided.

The [engine behavior contract](../Docs/Plan/Engine-Contract.md) specifies shared charging, retry and history semantics and intentional memory/SQLite differences.
